# 🛍️ Ecommerce Auth App

This is a **full-stack MERN (MongoDB, Express, React, Node.js)** E-commerce app with **JWT-based authentication.**  
It allows users to **sign up, log in, and access a protected product dashboard.** Users can **search, paginate, add products to a cart, and manage the cart** in a clean, responsive UI.
